# Introduction

OpenMerge is an AI-powered GitHub PR reviewer. Install it as a GitHub App, and it automatically reviews every pull request using three specialized agents.

## Overview

OpenMerge connects to your GitHub repositories via a GitHub App and reviews pull requests automatically. When a PR is opened, OpenMerge runs security, performance, and code quality agents in parallel, then posts inline comments directly on the diff.

## Key capabilities

- **Multi-agent parallel review** — Three specialized agents run simultaneously on every PR.
- **Inline diff comments** — AI findings are posted as line-level review comments.
- **GitHub App integration** — Installs in 30 seconds. Webhooks trigger reviews automatically.
- **Configurable rules** — Ignore paths, adjust severity thresholds, disable specific agents per repo.

## Installation

Install the OpenMerge GitHub App:

```bash
# Visit the GitHub Marketplace
https://github.com/apps/openmerge/installations/select_target
```

## Quick start

1. Install the GitHub App on your repositories.
2. Open a pull request — OpenMerge reviews it automatically.
3. Review inline comments posted by the OpenMerge bot.
