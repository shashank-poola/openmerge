# Configuration

Add a `.openmerge.yml` file to the root of your repository to configure review behavior.

## Basic config

```yaml
agents:
  code_quality: true
  security: true
  performance: true

ignore:
  - "**/*.test.ts"
  - "migrations/**"
  - "*.generated.*"

severity_threshold: warning
```

## Options

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `agents.code_quality` | boolean | `true` | Enable code quality agent |
| `agents.security` | boolean | `true` | Enable security agent |
| `agents.performance` | boolean | `true` | Enable performance agent |
| `ignore` | string[] | `[]` | Glob patterns to exclude from review |
| `severity_threshold` | string | `warning` | Minimum severity to report (`info`, `warning`, `error`) |
